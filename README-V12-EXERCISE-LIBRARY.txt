GYM COMEBACK V12 — BETA NOTES

What's new
1. VERSION V12 badge remains fixed at the top-right of the app.
2. About section identifies V12.
3. In Settings > Build your programme, the “Show weight fields for bodyweight and mobility exercises” checkbox is OFF by default.
4. When off, the weight (kg) input is hidden for bodyweight and mobility exercises. Reps, notes, reps-in-reserve, and symptom tracking remain available.
5. Tick the checkbox to show weight fields when recording added resistance, such as a weighted vest or dumbbell held during a bodyweight movement. The preference is saved on this device.
6. Existing V11 injury-aware alternatives, smart progression, equipment matching, five workout days, exercise library, progress, CSV export, and JSON backup remain in place.

Suggested beta tests
- Confirm VERSION V12 is visible while navigating and scrolling.
- Open a bodyweight exercise: weight fields should be hidden by default, but reps and symptom controls remain.
- In Settings, tick the checkbox and return to the workout: weight fields should appear.
- Untick it again: fields should hide without deleting saved workout entries.
- Check a machine/free-weight exercise: its weight fields should remain visible.
- Test safer swaps, logging, CSV export, JSON backup, and restore.

Safety note: exercise suggestions are not medical clearance. Stop if symptoms worsen and follow qualified clinical advice.

Build status: syntax and archive checks performed; not deployed to GitHub Pages and not live-tested on the user's phone.
