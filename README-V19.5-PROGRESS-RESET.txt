GYM COMEBACK V19.5 — BETA

WHAT'S NEW
• Safe Reset All Progress control in Settings > Backups & privacy.
• Two-step confirmation: browser confirmation, then type RESET.
• Clears saved workout sessions, set completion statuses, recorded weights/reps, body-weight entries, personal bests and adaptive review history.
• Keeps your profile, gym/home equipment, custom equipment, workout choices, programme length and app preferences.
• Returns the current workout to Week 1 and clears unsaved entries on screen.
• Retains the V19.4 Adaptive Training Review and all previous passed features.

BEFORE RESETTING
Export a JSON backup first if you may want the old history later. The reset is permanent for this browser/device unless you restore a backup. If you have already saved your sessions elsewhere, you can proceed when ready.

INSTALL
1. Keep your V19.4 ZIP as a backup.
2. Extract this ZIP.
3. Upload the CONTENTS of the extracted folder to the same GitHub Pages root used by Gym Comeback. Do not upload the ZIP itself or put the files in a nested folder.
4. Commit/publish the changes.
5. Open the site in Chrome and refresh. If the installed PWA still shows V19.4, close it fully, open the website in Chrome to allow the service worker to update, then reopen the app.

TEST
First test the new control without confirming the final typed RESET step. Confirm that it cancels safely. Only type RESET when you are ready to clear your own saved progress.

V19.5 is a beta package. It has passed source-level syntax, structure and ZIP integrity checks, but has not been deployed or tested on your phone/PC by the developer.
