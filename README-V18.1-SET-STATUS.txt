GYM COMEBACK V18.1 — SET STATUS CLARITY

Install: Extract this ZIP and upload the contents to the existing GitHub Pages repository, preserving the current folder structure.

Changes:
- Each set clearly displays NOT STARTED, IN PROGRESS, or COMPLETED.
- Tapping or entering weight/reps marks that set IN PROGRESS.
- Tapping SET COMPLETED marks the set COMPLETED and starts the rest timer.
- Started/completed states are saved separately for the selected week, day and date.
- Set status is cleared when the current week/day session is cleared. Existing workout logs are not overwritten by status tracking.

Test on phone and PC: check initial states, enter data into set 1, mark it complete, verify set 1 stays green/COMPLETED while set 2 remains NOT STARTED, change days and return, reload, and confirm statuses persist for the same date. Verify the rest timer, exercise swapping, progress charts and JSON backup/restore.

Keep V18 ZIP as a backup. Do not clear browser site data while testing. This beta has not been deployed or device-tested by the developer.
