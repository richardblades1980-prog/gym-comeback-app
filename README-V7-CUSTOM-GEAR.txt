GYM COMEBACK — V7 CUSTOM GEAR & EXERCISE LIBRARY

What's new
- New My Gear tab: select equipment available at your commercial gym and at home independently. This supports mixed setups where home and gym equipment differ.
- Equipment choices save locally on this device.
- Expanded equipment checklist covers free weights, benches/racks, selectorised and cable machines, leg machines, cardio machines, bands/accessories, mobility gear, and home/functional equipment.
- Exercise Library includes no-equipment/bodyweight exercises (push-ups, squats, burpees, lunges, glute bridges, planks, calf raises, core work and low-impact options), free-weight, resistance-band, cardio and mobility movements.
- Add/remove exercises from the current workout day. Exercise logging, muscle-group guide and workout completion still work with added exercises.
- Exercise logging restores by exercise name so adding/removing library items is less likely to shift recorded values.
- Backup JSON now includes custom gear and exercise selections.
- Service-worker cache version bumped to force the V7 files to refresh.

Install on GitHub Pages
1. Export a backup from the current app and back up your GitHub repository.
2. Extract this ZIP.
3. Replace index.html and sw.js in the same folder as the live app.
4. Copy the assets/ folder and retain cover-art.jpg, manifest.webmanifest, icons/ and the celebration GIFs (all included in this package).
5. Commit and push to the same GitHub Pages branch/folder.
6. Open the site once while online. If the old version remains, close the app, clear the site cache or remove/reinstall the home-screen shortcut after confirming your backup.

Notes
- Gear selections are currently a saved personal inventory and guide the user in choosing exercises; they do not automatically rewrite the base programme or guarantee an exercise is suitable.
- Exercise images use the best matching bundled comic-style equipment category available in this package. Some individual machine models will still share a category illustration; the library is designed so distinct artwork can be added over time.
- The exercise library is a reference, not medical advice. Choose pain-free variations, especially for jumping, standing and loaded movements. Stop for sharp or worsening pain, swelling or limping.
- Workout records and equipment selections are local to this browser/device unless exported and restored elsewhere.
