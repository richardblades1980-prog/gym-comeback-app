GYM COMEBACK V19 — EXERCISE COMPLETION CLARITY

Built from the passed V18.1 release.

WHAT CHANGED
- When all three sets of an exercise are marked complete, the whole exercise card takes on a subtle faded green background.
- A clear “✓ EXERCISE COMPLETE” label appears below the exercise name.
- The exercise number badge changes to green.
- The completed appearance is calculated from existing set-status records, so it follows the selected workout day/date and returns after the set statuses are restored.
- The green treatment is deliberately muted to remain visible without overwhelming the rest of the screen.

WHAT SHOULD REMAIN UNCHANGED
- Set status colours and labels.
- Smart rest timer and its controls.
- Workout logging, exercise swapping, progress charts and JSON backup/restore.
- Existing local workout data.

TESTING
Technical checks only have been run on the package. Please test on the target phone and browser before treating V19 as passed. Do not clear site data during testing. Keep V18.1 as the stable backup.
