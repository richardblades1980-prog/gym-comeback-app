GYM COMEBACK V15 — COMMUNITY EDITION
=====================================

Built from the user-tested V14 baseline. V14 remains available as a separate backup.

WHAT'S NEW
- Dismissible quick-start guide on the Train page. It explains the first steps without changing the training plan.
- Display & accessibility options in Settings: larger text, higher contrast, and reduced animations. Preferences are stored locally on this device.
- Clearer privacy and backup guidance, including a reminder that JSON backups contain personal training/profile details and should be stored privately.
- App version badge, About section, footer, and service-worker cache updated to V15.

RETAINED FEATURES
- V14 progress dashboard, bodyweight tracking and trend chart, strength trend charts, recent sessions, personal bests, CSV export, JSON backup/restore.
- V13.1 repeated exercise swap fix, V12 bodyweight/mobility load-field preference, V11 injury-aware alternatives, V10 smart progression, equipment matching, custom gear, exercise library, five training days, muscle/equipment guides.

IMPORTANT
- This ZIP is a beta package. It is not automatically deployed to GitHub Pages. Upload/publish its contents only when ready.
- Data is stored in this browser on this device; it does not automatically sync across devices. Export JSON backups regularly. Keep backup files private.
- Restoring a backup replaces matching week/day workout records. Do not test restore on valuable data without first downloading a fresh backup.
- Exercise suggestions are not medical clearance. Stop movements that cause worsening pain and seek qualified advice for new, severe or worsening symptoms.
