Install:
1. Back up the existing repository and export workout data before changing anything.
2. Replace index.html and sw.js with these V9 files.
3. Copy assets and all included app files into the existing GitHub Pages repository.
4. Commit and push.
5. Open the site while online and verify V9 loads.

Data note: existing V8 profile data remains compatible; newly added fields are optional. Workout logs and settings are stored locally in the browser. This package has not been pushed to the user's GitHub repository.
