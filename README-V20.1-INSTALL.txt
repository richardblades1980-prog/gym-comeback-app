GYM COMEBACK V20.1 – INDIVIDUAL EXERCISE PROGRESSION

INSTALL / UPDATE
1. Keep your previous ZIP as a backup.
2. Extract this ZIP.
3. Upload the CONTENTS of this folder to the root of your existing GitHub Pages repository, replacing the old files.
4. Commit/publish the changes.
5. Open the website in Chrome and refresh. Confirm V20.1 appears in the app's top-right version badge.

WHAT'S NEW
- Individual set counts per exercise (1–8 sets).
- Per-exercise progression preference: reps first, weight first, duration first, sets first, balanced, or manual.
- Timed exercises can record duration per set.
- Existing V20 readiness and adaptive review features are retained.

BETA TESTS
- Change Plank to 2 sets and record 60 seconds for each set.
- Change Squats to 3 sets with reps-first progression.
- Change Bench Press to 4 sets with weight-first progression.
- Confirm settings remain independent per exercise and persist after leaving/reopening the workout.
- Check completion status and backup export.

NOTES
- This is a beta build. Test before relying on it.
- Keep V20 as a known-good backup.
- This ZIP contains only the current install guide; historical release notes are intentionally omitted to make GitHub's file upload easier.
