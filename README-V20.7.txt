GYM COMEBACK V20.7 — SMART SET CARRY-FORWARD

This beta builds on the passed V20.6 package.

NEW IN V20.7
1. When an earlier workout exists, matching exercise set values are copied forward as editable starting points.
2. When a set value is edited, later sets that are still linked/auto-filled copy that value.
3. Manually edited later sets are preserved; editing that set can then carry its value forward to subsequent linked sets.
4. Weight, reps and timed duration are supported.
5. Existing sequential set locking remains: future sets stay visible but disabled until the prior set is completed.

BETA TEST
- Enter a value in Set 1 and confirm later sets copy it.
- Change Set 1 and confirm linked later sets update.
- Manually change Set 2, then change Set 1; confirm Set 2 is preserved.
- Change Set 2 and confirm Set 3 follows it if still linked.
- Check values from a previous workout carry forward when opening the next matching workout.
- Test weight, reps and timed duration, and exercises with different set counts.
- Save, leave the workout, reopen it and confirm values remain.
- Confirm sequential set completion, automatic collapse, workout-day locking, numeric keyboards and back-to-top still work.
