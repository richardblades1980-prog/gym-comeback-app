GYM COMEBACK — V21.1A.1 BETA
Stage A: Objective refresh usability fix

INSTALL / UPDATE
1. Extract this ZIP package.
2. Upload the contents of the gc206 folder to the same GitHub Pages location used by your current Gym Comeback beta, replacing the previous app files.
3. Open the app and refresh it. If an older version remains visible, close the app/browser tab and reopen it so the updated service worker can take effect.
4. Check the version badge at the top-right: VERSION V21.1A.1.

WHAT CHANGED
- Changing the primary objective now saves the objective selection immediately after confirmation.
- Changing the secondary objective also saves immediately.
- Exercise progression suggestions refresh without resetting objectives, rebuilding the plan, or saving the full profile.
- Existing exercise-specific progression choices remain unchanged. The coach suggestion updates, but the user's chosen progression method is not silently overwritten.
- Workout history is retained.

BETA TEST
1. Open Coach and change the primary objective (for example, Strength). Confirm the change.
2. Return to Train and check that exercise suggestions reflect the new objective. No plan rebuild or profile save should be required.
3. Change the secondary objective and confirm the objective status updates.
4. Set an exercise to a manual progression preference, change the primary objective, and confirm the chosen preference remains manual while the coach suggestion updates.
5. Reload the app and check that the selected objectives remain saved.
6. Confirm workout history and existing exercise settings remain intact.

This is a beta build. Test before relying on it. Your working data remains in this browser on this device; use the app's backup feature before updating.
