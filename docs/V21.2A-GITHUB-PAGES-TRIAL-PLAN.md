## 14. Owner-confirmed Gym set population rules (2026-11-19)

The owner confirmed two separate behaviours:

1. Programme-week carry-forward by exact programme slot and set number, preserving a manually adjusted set's own value into the next week.
2. Within each exercise, Set 1 weight/reps populate later locked/not-started sets. Timed target duration may copy; actual measured duration does not.

A later set's manual edit (including a reduction) is independent and does not change following sets. If Set 1 changes, only automatic default fields follow it; user-owned, started and completed fields remain unchanged. The UI labels automatic defaults “From Set 1 · editable”. Auto-population does not change the existing sequential lock rules.
