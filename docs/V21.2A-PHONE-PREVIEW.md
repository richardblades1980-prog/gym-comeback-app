# V21.2A Phone Preview

Status: development preview only. This is not the live V21.1 application and is not a production release.

## Open on a phone

Development preview URL:

https://raw.githack.com/richardblades1980-prog/gym-comeback-app/V21.2-development/v21.2/index.html

The preview is served by raw.githack, a third-party static-file CDN/proxy for public GitHub repositories. The URL follows its documented development-branch format. It may show a brief HTML confirmation page before opening the app. It is a convenience preview, not a guaranteed-uptime host.

The repository is public, so the app source is public. The app's records are stored in browser IndexedDB on the preview origin; they are not written back to GitHub. Do not enter sensitive or valuable personal data in this preview. Use test entries only and download a backup if you want to keep the test data.

## Important origin limitation

This preview runs on the raw.githack.com origin, not the origin that hosts V21.1. Browser localStorage and IndexedDB are origin-scoped. Therefore this isolated preview cannot see or migrate V21.1's existing localStorage data. The V21.1 migration workflow has passed the controlled Chromium browser test; testing migration against the user's actual V21.1 data requires hosting V21.2 under the same origin as V21.1 (or a separately designed export/import bridge). Do not attempt to migrate real data in this third-party-origin preview.

## Phone regression checks

1. Open the preview URL in the phone browser and allow the page to finish loading.
2. Confirm the Overview screen appears and the connection indicator says Local database ready.
3. Open Hiking, add a clearly labelled test hike with a small positive distance and a route name, and confirm it appears in Hiking history.
4. Open Schedule, add a future test Gym or Hiking activity, and confirm it appears.
5. Open Data & backup and download a full backup. Confirm the JSON file is saved.
6. Reload the page and confirm the test hike and scheduled activity remain.
7. If the browser offers Add to Home Screen / Install, try it only as an optional check. The app shell should be available offline after its first successful load and service-worker installation; test by temporarily enabling airplane mode and reopening the preview.
8. Do not use the V21.1 migration controls in this preview. Do not use real training records or personal information.

Report any layout issue, missing button, validation problem, failed save, backup problem or offline failure. Keep V21.1 and the main branch unchanged.
