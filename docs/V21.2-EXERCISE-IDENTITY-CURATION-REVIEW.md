## Decision standard

A verified alias is a source-scoped, exact-string mapping to one exercise definition. It does not erase the source label or its historical snapshot. A variation is a separately identified execution difference under a reviewed parent definition. Similar muscle targets, equipment keywords or normalized names are not sufficient evidence by themselves.

The source's `baseExerciseReady()`, `machineDescriptions`, `equipmentAsset()` and optional-library gear-match fields are considered separately below. Gear-match text is equipment availability data, not an alias list.

## Machine nomenclature clarification supplied by the user

The following terminology was supplied to distinguish common machine labels and physical configurations. It is useful curation evidence, but it does not establish which equipment the original programme author intended or which machine is installed at the user's gym.

- **Chest press:** Seated Chest Press, Machine Bench Press and Vertical Chest Press are naming descriptions often used for an upright machine press. Converging Chest Press describes handles moving inward; Iso-Lateral Chest Press describes independent arm movement, often on plate-loaded equipment. Preserve handle path and independent-arm mechanics as variation attributes when they materially affect execution.
- **Leg press:** 45-Degree Leg Press identifies an angled sled; Seated Leg Press identifies a horizontal/pin-selected configuration; Vertical Leg Press identifies a vertical push configuration. “Sled Press” is informal wording associated with the angled sliding carriage, not a safe universal alias for every leg press.
- **Leg extension:** Quad Extension Machine, Knee Extension Machine and Leg Extension are common names for the knee-extension machine movement. The base-programme label explicitly says **Seated**; do not discard that attribute unless the library row's intended equipment is confirmed.
- **Shoulder press:** Overhead Press Machine, Machine Military Press and Deltoid Press are common naming alternatives for a machine shoulder press. Converging Shoulder Press describes a particular handle path and should be represented as a variation attribute where appropriate.

**Unresolved equipment detail:** the exact brand/model and whether the installed machines are pin-selected, plate-loaded, converging or iso-lateral have not been provided. The user has confirmed a gym-wide mixture of pin-selected and plate-loaded machines. That establishes the catalogue must support both loading systems, but does not identify the loading system or movement geometry of any particular machine. The legacy programme's gear matcher and equipment illustrations do not resolve those details. Therefore the broad machine-family relationships remain candidates, not verified aliases or variations.
