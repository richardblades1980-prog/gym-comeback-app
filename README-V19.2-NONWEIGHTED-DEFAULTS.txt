GYM COMEBACK V19.2 — WEEKLY DEFAULTS FOR NON-WEIGHTED EXERCISES

Built from the passed V19.1 weekly defaults release.

WHAT CHANGED
- Ensures previous reps carry forward for bodyweight, mobility and other non-weighted exercises even when the weight field is hidden.
- Matches exercise names case-insensitively and tolerates punctuation/spacing differences.
- When a current week already has saved entries, fills only blank weight/rep fields; existing values are not overwritten.
- Copies from the most recent earlier matching workout day and keeps all copied values editable.
- Week 1 still starts fresh. Dates, bodyweight, cardio, notes, effort and symptom fields are not copied.

TESTING
- JavaScript syntax, manifest JSON, duplicate HTML IDs, service-worker cache reference, and ZIP integrity checked.
- Static checks are not a substitute for phone/PC beta testing.

BACKUP
Keep the passed V19.1 ZIP. Do not clear browser site data; workout logs are stored locally on the device/browser.
