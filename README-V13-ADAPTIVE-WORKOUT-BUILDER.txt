GYM COMEBACK V13 — BETA NOTES

WHAT’S NEW
1. VERSION V13 badge stays fixed in the top-right corner; About and footer identify V13.
2. New “Build my personalised week” button on the Train page.
3. Uses saved profile information: goal, training experience, days per week, session-length target, recovery, preferences and restriction/pain details.
4. Requires selected equipment in My Gear, then activates gear-matched versions of the selected 2–5 training days. Days beyond the chosen frequency return to the original workout.
5. Candidate substitutions use muscle overlap, equipment availability, goal/recovery context and symptom caution rules. High pain or broad restrictions trigger a confirmation prompt.
6. Existing logs and manually selected swaps are preserved.

TESTS TO TRY
- Confirm VERSION V13 stays visible while navigating and scrolling.
- Save some equipment in My Gear, select Gym/Home, and build a personalised week.
- Change days per week from 2 to 4 and rebuild; check day selectors and active workouts.
- Try a home setup with limited equipment and verify the builder gives sensible equipment-matched substitutions.
- Select a restriction and confirm the safety note appears; set pain to 7/10 and confirm the extra prompt appears.
- Check V12’s bodyweight/mobility weight-field checkbox.
- Verify safer swaps, progression, logging, all five days, CSV export, JSON backup and restore.

SAFETY
The builder is a transparent rule-based aid, not a medical assessment. It cannot guarantee an exercise is safe. Review every movement, follow clinician restrictions, and stop if symptoms worsen.

BUILD STATUS
JavaScript syntax and ZIP integrity checks are required before release. Not deployed to GitHub Pages or tested on the user’s phone.
