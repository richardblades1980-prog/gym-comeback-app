GYM COMEBACK V20.6 — SEQUENTIAL SET COMPLETION

INSTALL / UPDATE
1. Keep your passed V20.5 ZIP as the rollback backup.
2. Extract this ZIP.
3. Upload the CONTENTS of the extracted folder to the root of your existing GitHub Pages repository, replacing the previous files.
4. Commit and publish.
5. Open the site in Chrome, refresh, and confirm VERSION V20.6 appears in the top-right badge. If the installed PWA shows an old version, open the website in Chrome once to allow the service worker to update.

WHAT'S NEW
- Set 1 is available immediately; each later set remains visible but disabled until the previous set is completed.
- Completing a set unlocks the next set. The rule works with each exercise's individual set count (1–8).
- Completed sets can be reopened by tapping the completed button. Reopening a set clears that set and all later set completions for that exercise, requiring the sequence to be completed again.
- Set status and sequence are restored when returning to the workout and remain compatible with exercise collapse.
- All V20.5 back-to-top and numeric keyboard improvements are retained.

BETA TEST CHECKLIST
1. Choose an exercise configured for at least 3 sets. Confirm Set 1 is enabled and Sets 2+ are visible but disabled.
2. Complete Set 1. Confirm Set 2 becomes enabled while Set 3 remains disabled.
3. Complete Set 2. Confirm Set 3 becomes enabled.
4. Complete the remaining sets and confirm the exercise collapses as before.
5. Expand the exercise and tap the completed button for Set 1 to undo it. Confirm Set 1 is available, all later sets are reset and disabled, and the sequence can be completed again.
6. Test an exercise configured for 2 sets and another configured for 4 or more sets.
7. Navigate away and back; confirm the statuses and locks restore correctly.
8. Confirm back-to-top, numeric keyboards, workout-day/week locking, warm-up/cool-down, backup/restore and version badge still work.

DEVICE NOTE
Disabled future sets are still displayed so the complete exercise plan remains visible.
