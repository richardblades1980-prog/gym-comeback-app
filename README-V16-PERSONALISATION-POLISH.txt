GYM COMEBACK V16 — PERSONALISATION & POLISH (BETA)

Built from the passed V15.1 Community Edition.

NEW IN V16
- At-a-glance panel on Train page with saved session count, last saved session, and selected day.
- Quick save shortcut uses the same existing Save Session flow; it does not create a second logging system.
- Quick link to Progress.
- Choose which section opens when the app starts.
- Remember a preferred workout day across reloads on this device.
- Stronger keyboard focus indicator and improved mobile touch target sizing.
- Reduced-motion setting continues to suppress interface animations.

PRESERVED
- V15.1 community/accessibility features.
- V14 progress dashboard, standalone weigh-ins, strength/bodyweight charts and JSON backup/restore.
- Exercise library, equipment matching, exercise swaps, injury-aware alternatives, smart progression, and the bodyweight load-field preference.

PRIVACY
Preferences and workout logs are stored locally in this browser on this device. They do not sync automatically between devices. Keep JSON backups in a safe place.

INSTALL / UPDATE
1. Keep the V15.1 ZIP as a stable backup.
2. Extract this ZIP.
3. Upload the extracted package contents to the existing GitHub Pages repository, preserving the folder structure.
4. Commit and wait for Pages to publish. Refresh the site on computer and phone. If a stale screen appears, close/reopen the app first; do not clear site storage unless you have a verified backup.

TEST CHECKLIST
- Open Train, confirm the at-a-glance card loads.
- Change workout day, reload; selected day should persist.
- Save a test session using the quick save button and confirm it follows the existing save/celebration flow.
- Visit Progress and verify charts and existing records.
- Set app start page to Progress, reload; it should open there. Reset to Train afterward if preferred.
- Confirm My Gear, Coach, exercise swaps, injury-aware alternatives, bodyweight weight-field setting, CSV export and JSON backup/restore still work.

This ZIP has passed static syntax/manifest/ZIP checks, but needs browser and phone beta testing. It has not been deployed to GitHub Pages by this package creation.
